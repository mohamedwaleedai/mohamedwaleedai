# Mohamed Waleed

AI engineer and instructor based in Cairo. I build document and language systems in Arabic and English. I teach AI and data science.

## Selected projects

- **[Legal_contracts_NLP](https://github.com/mohamedwaleedai/Legal_contracts_NLP)**: Arabic legal contract analyzer. Splits a contract into clauses, retrieves relevant articles of Egyptian law with hybrid search, and flags void or one-sided terms. Team project with [@Mohamadadel510](https://github.com/Mohamadadel510).
- **[medfoundation](https://github.com/mohamedwaleedai/medfoundation)**: a typed contract layer for medical AI pipelines. Every clinical claim must cite a verbatim span of stored evidence and stays unverified until a named human reviews it. Includes a workflow runtime, document ingestion, a clinical NLP engine and a read-only chart viewer, with 398 tests.
- **[asl-alphabet-recognition](https://github.com/mohamedwaleedai/asl-alphabet-recognition)**: real-time ASL fingerspelling recognition from a webcam, using MediaPipe hand landmarks and a small Keras classifier. The README is explicit about what has and has not been verified.
- **[ml-notebooks](https://github.com/mohamedwaleedai/ml-notebooks)**: exploratory notebooks on preprocessing, segmentation, classification, regression, forecasting and text classification, each with its caveats written down.
